# L4 · gc runs by itself, and finishes: plan

Spec: `docs/specs/2026-10-25-resource-lifecycle.md` §L4. Features L4-01 to L4-05; L4 is independent (`after: []`).
Order inside `cmd_gc` stays: units → tmux reap → fetch → desks → worktrees → (`--deps`) → record-only tails →
branch passes (the unit step first, decisions/2026-10-25-gc-orphan-units).

## 1. The branch passes (L4-01)

One loop over prefixes, never a `*` glob (on git 2.43 `refs/heads/*` doesn't cross a `/`):

```bash
local prefixes=(harness/ harness-merge/); (( all )) && prefixes+=('')   # '' = refs/heads/ itself: every branch
for pre in "${prefixes[@]}"; do
  local:  git for-each-ref --format='%(refname:short)'   "refs/heads/$pre"            → branch -d (skip main, current)
  remote: git for-each-ref --format='%(refname:lstrip=3)' "refs/remotes/origin/$pre"  → push --delete (skip main, HEAD)
done
```

Every pass runs (no `break`); a branch an earlier pass handled is skipped by the bare pass (a `seen` set, so a
`--dry-run` prints each `would:` once). Merged = `merge-base --is-ancestor <b> origin/main`; local deletes stay `-d`.
The record-only-tails pass lists `refs/heads/harness/` (prefix) too.

## 2. Removal finishes (L4-02)

Per worktree: `git worktree remove --force` (only reached for a clean tree: `status --porcelain` empty), then
`rm -rf` if the directory is still there, then `git worktree prune`; any failure prints `! could not remove <wt>: <why>`
(the last stderr line) and the loop goes on. `act` must not end gc under `set -e`: the removal runs as an `if`.
Finding while planning: git 2.43 here removes a worktree whose only extra files are ignored (`.next/` via
`.gitignore` or `info/exclude`) *without* `--force`; R9's refusal (portfolio_site) had another cause (a file gc
couldn't delete, or the loop dying under `set -e`). The fix is the fallback chain plus going on, not `--force` alone.

## 3. `--deps` (L4-03)

For each worktree under `$WT_ROOT/<project>/` (never `$p` itself, never outside `$WT_ROOT`), its run is the one whose
state dir (`$STATE_ROOT/<project>/<run>`) has `meta.env` `WT=` that path. Guards, all must hold: `ended` exists; no
live `driver.pid` (`alive`); no `$Q/*-continue-<run>.args`; no open desk (`desk_open`). Then for each of `DEPS_DIRS`
that exists as a directory (not a symlink): `du -sm` the set, delete, print `+ freed <n> MB in <wt>: <dirs>`
(`would: freed …` on `--dry-run`). Merged or not: the branch keeps the work; nothing tracked is touched (the check
asserts `git status --porcelain` is empty after).

## 4. The runner's gc (L4-04)

`lib/queue.sh`, after the tmux reap and before the debrief line, when `started > 0`: the distinct
`PROJECT_DIR`s (from `meta.env`) of the state dirs whose `runners` holds `$RID`; for each,
`log "gc <name>: harness gc <dir> --all-merged --deps"`, run it with each output line logged as `gc <name>: <line>`;
a non-zero exit logs `gc <name> failed (exit <n>)` and the debrief starts anyway.
