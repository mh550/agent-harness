One Opus round on `git diff $(git merge-base HEAD origin/main) -- lib bin prompts tests docs journal templates README.md`

## The five questions

1. **No path merges a PR whose body refresh failed: holds.** `memory_edit` (lib/record.sh, `memory_edit()`) returns
   `gh pr edit`'s status; on the push path `memory_pass` returns it (`memory_edit … || return 1`) and `memory_pr` reads
   it as `fbody=$?` right after `memory_pass facts`; the merge (`if (( fbody == 0 )); then memory_merge …`) is the only
   `memory_merge` call. A fresh PR's `pr create --body-file` carries the body (`fbody` 0); a failed create leaves
   `PASS_URL` empty, so `$url == http*` fails; the no-change path leaves `PASS_HEAD` empty, so `-n $fhead` fails. The
   second edit (naming the rules PR) does not decide the merge, the decision's stated default.
2. **The deny list reaches the curator's `claude` line alone: holds.** `local S_DENY=("${CURATOR_DENY[@]}")` in
   `curator()` (lib/driver.sh) is function-local, seen by `session` through bash's dynamic scope and gone when
   `curator` returns; `curator()` calls no other `session`. `grep -n S_DENY lib/*.sh`: driver.sh's one assignment and
   record.sh's `[[ -v S_DENY ]] && (( ${#S_DENY[@]} )) && deny=(--disallowedTools "${S_DENY[@]}")`, last on the
   `claude -p` line. The `cu` run's argv files (curator-run.sh) show the flag on the curator's and none on the coding,
   verify or retro's.
3. **The match is by key: tier 1 holds, a different sentence failed (Important 1, fixed).** `tier === 1 ? undefined`
   on the re-derived tier (never the op's claim). The key was `factKey`'s first 40 characters, so two rules sharing
   them were one verdict.
4. **A replaced verdict is counted once: holds.** `upsert` (lib/memory.mjs) filters on `<run>/<n>` and key then
   appends; `latestAnswers` (lib/curator.mjs) dedupes on the same identity, so even a hand-appended duplicate counts
   once; `answersTally` counts over it (tests/unit/memory.test.mjs, `a row replaces an earlier one …`).
5. **`harness memory` with an empty, missing or malformed answers file: holds.** `summary.mjs memory` reads it with
   `tolerant` (missing → none, an unparseable line skipped); `latestAnswers` drops a row without a string `run`, an
   integer `n` or a verdict. Run by the reviewer: missing and empty print `answers: accepted 0 · declined 0`; `{bad`,
   `null`, `[1]` and a string `n` are skipped, exit 0.
